# Blinkit Sales & Operations Analysis

## Project Overview

This project focuses on analyzing Blinkit's sales performance, customer trends, and feedback using Microsoft Power BI. The dashboard presents key performance indicators (KPIs) and interactive visualizations to help explore business performance and identify meaningful insights.

## Tools & Technologies

- **Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Data Modeling** – Organizing data for analysis

## Dashboard Pages

### 1. Sales Overview
- Sales performance and year-over-year comparisons
- Year-to-date (YTD) sales analysis
- Product and payment-related insights

### 2. Customers Overview
- Customer growth and trends
- Repeat customer analysis
- Customer-related performance indicators

### 3. Feedback Overview
- Customer feedback and sentiment analysis
- Ratings and feedback categories
- Customer satisfaction insights

## Key Insights

- Analyzed sales performance across 2023 and 2024.
- Identified a reported **32.5% growth** during the first nine months of the comparison period.
- Compared year-to-date sales to understand changes in business performance.
- Explored customer trends and feedback to support business analysis.
